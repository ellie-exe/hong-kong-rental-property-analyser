# Hong Kong Rental Property Market Analyser

A Python web-scraping project built with Selenium to search and extract Hong Kong rental property listings based on user-selected criteria.

## Features

- Filter by property type, budget, saleable area, number of rooms, and district
- Extract property name, address, monthly rent, area, bedrooms, bathrooms, and listing URL
- Support data extraction from property listing pages
- Export results to CSV
- Create new CSV files or append results to existing files
- Headless browser automation using Selenium

## Technologies

- Python
- Selenium
- CSV

## How It Works

1. User selects property preferences
2. The scraper applies the filters
3. Matching property listings are extracted
4. Results can be saved or appended to a CSV file

## Project Context

Developed as an individual course project at HKUST.
